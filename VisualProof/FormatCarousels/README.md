# Import and export format carousel proof

These rasters are generated by `Tools/SceneDirectoryProof/SceneDirectoryProof.cpp` from the real `WorkspacePanel`, `EditorPanel`, `SceneDirectoryPanel`, and `TexturePaintPanel` through the production recording surface.

- `editor-scene-transfer.png` — Scene Directory Import mode with FBX, glTF, GLB, OBJ, USD, USDZ, DAE, STL, PLY, and Alembic choices.
- `editor-scene-export.png` — Scene Directory Export mode after its right carousel arrow advances the selected format.
- `editor-layer-flatten.png` — the non-destructive Export Flattened destination with image-format and resolution carousels.
- `editor-layer-export.png` — the separate Layer Stack Export destination after both its format and resolution carousels advance.

The runtime scenarios assert the footer modes, outer page separation, and arrow interactions rather than setting the carousel readings directly.
