How junctions work

Every crossing splits both roads into a shared node (never a “+” drawn over a “|”). Degree ≥ 3 nodes become one filleted patch: arms trimmed to the boundary, hub built ring→inner quads + n-quad centre. Output stays 100 % quads, welded, no degenerate faces.
